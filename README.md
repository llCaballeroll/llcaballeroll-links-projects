# Luis Angel Caballero Jardón | Juegos y Libro

Página web tipo Linktree creada para centralizar los accesos principales a mis proyectos digitales.

## Contenido

- Snake Islands
- Amon Oracle
- Bounce Royale
- Libro: Sin Párpados
- Contacto por WhatsApp
- Redes sociales

## Objetivo

Esta página está pensada para usarse con un código QR y redirigir a los usuarios a un solo lugar donde puedan acceder a mis juegos, libro y medios de contacto.

## Tecnologías usadas

- HTML5
- CSS3
- Diseño responsivo
- Modo oscuro
- Estilo visual inspirado en interfaces modernas tipo Apple
